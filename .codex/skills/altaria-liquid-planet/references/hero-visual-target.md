# Altaria Lights Hero Visual Target

The hero should feel close to the Bloom AI reference but adapted to Altaria Lights.

Do:

- Full-screen video background.
- Purple planet / violet glow.
- Liquid glass UI.
- Floating panels.
- Premium AI/tech landing feeling.
- Strong responsive composition.
- Text readable over video.
- Smooth hover states.
- Subtle motion only.

Do not:

- Copy Bloom text.
- Use green as the main accent.
- Add random sections unrelated to Altaria.
- Hide the planet with too many cards.
- Use hard flat borders everywhere.
- Create a generic SaaS hero with plain gradients.
- Replace the whole website unnecessarily.

Suggested palette:

- Background: near black / deep navy.
- Text: white, white/80, white/60.
- Accent: violet, purple, lavender.
- Glass: white at very low opacity.
- Glow: violet/purple shadows.
